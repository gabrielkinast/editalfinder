### Como Executar
1. Acesse a pasta do projeto: cd EditalFinder-React
2. Instale as dependências: npm install
3. Copie `.env.example` para `.env.local` (ou `.env`) e preencha `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` (chave **anon** do Supabase — nunca use service_role no frontend).
4. Inicie o projeto: npm run dev

### URL no navegador (obrigatório)
O Vite está configurado com base **/editalfinder/** (igual ao React Router).

- Abra: **http://localhost:5173/editalfinder/** (com a barra final).
- Se abrir só **http://localhost:5173/**, o servidor redireciona para /editalfinder/ em modo dev.

Se aparecia **HTTP 404** nessa URL, a causa era a falta de **index.html** e **src/main.jsx** na pasta EditalFinder-React (o Vite subia, mas não havia página React). Isso já está corrigido no repositório.
